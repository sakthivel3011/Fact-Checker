Course Rubric Mapping

  • C1 Functional: Live Fact Verification + Category-wise News Digest + Interactive UI + Export (Markdown/JSON).
  • C2 Architecture: LangGraph StateGraph with conditional edges and TypedDict state tracking.
  • C3 MCP: Model Context Protocol server (mcp_server.py) with 5 exposed tools and 3 resources.
  • C4 Tools: Tavily search, domain credibility evaluator, clickbait detector, RSS scraper.
  • C5 RAG: Vector store similarity search over verified ground truth benchmark claims.
  • C6 Prompts: System prompts, few-shot reasoning exemplars, and Pydantic structured outputs.
  • C7 ReAct + Tavily: Multi-step Thought-Action-Observation loop with live Tavily web search.
  • C8 Env & Config: Clean requirements.txt, .env.example, .gitignore, and config.py.
  • C9 Code Quality: Modular, type-annotated, PEP-8 compliant code.
  • C10 Safety: Prompt injection defense, citation grounding check, and credibility floor.
  • C11 Testing: Pytest unit and integration test suite with high test coverage.
  • C12 Documentation: Detailed README with Mermaid diagrams, setup steps, and sample runs.
